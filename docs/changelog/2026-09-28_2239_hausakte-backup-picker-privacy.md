# Backup-Auswahl und Datenschutz an Fahrzeugakte angleichen

Backup-Dateiauswahl auf den exportierten binären Dateityp beschränken und die
zusätzliche Prüfung der Endung `.habackup` beibehalten. Die Datenschutzkarte
übernimmt Texte, Kontakt und Link-Verhalten der Fahrzeugakte. Vollständige
Erklärung in `PRIVACY.md` mit fachlich passenden Hausakte-Angaben. Externe Links
für Datenschutz und Quellcode öffnen das eigene GitHub-Repository.

Keine umfangreichen Tests auf Nutzerwunsch. Manuelle Prüfschritte und tatsächliche
Prüf-, Veröffentlichungs- und Installationsstände stehen in `docs/VALIDATION.md`.

Formatprüfung, ESLint, TypeScript strict und Preview-Build bestanden. APK nach
Identitäts- und Signaturprüfung datenbewahrend installiert. Backup-Dateifilter,
Abbruch, Kontaktkarte und Start des Datenschutz-Links kurz auf Android geprüft.
Auf ausdrückliche Freigabe nur `PRIVACY.md` veröffentlicht, Link mit HTTP 200
und identischem Dateiinhalt bestätigt. Sonstige Änderungen bleiben lokal.
